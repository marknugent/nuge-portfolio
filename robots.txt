# Intent: shareable by link, absent from search results, and off-limits to AI
# training crawlers.
#
# Note the deliberate asymmetry below. Search engines are ALLOWED to crawl.
# That looks backwards, but it is the only way to stay out of results: the
# `X-Robots-Tag: noindex` header this site sends on every response (see
# .htaccess) can only be obeyed by a crawler that is permitted to fetch the
# page and read it. A robots.txt `Disallow` blocks the fetch, so the crawler
# never sees the noindex — and Google may then list the bare URL anyway if it
# finds a link to it somewhere else. Allow the fetch, and the noindex applies:
# the page is dropped entirely.
#
# AI and training crawlers get the opposite treatment: they are blocked
# outright, because the goal there is no fetching at all, not de-indexing.
